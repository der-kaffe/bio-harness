# Proportional private SDD

- **TRIVIAL:** direct implementation and focused validation.
- **SMALL:** implementation/tests; a brief plan only when useful.
- **MEDIUM:** lightweight private specification when durable reasoning helps.
- **LARGE/RISKY:** proportional requirements, decision, specification, design, and plan; create only the documents needed.

Do not force `tasks.md` or the full template set. Private specifications guide personal Codex work and do not silently become team authority. Propose promotion into the repository's existing shared convention when collaborators genuinely need the contract.
