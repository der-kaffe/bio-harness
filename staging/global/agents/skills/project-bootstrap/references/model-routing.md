# Proportional model routing

Correctness, safety, required reasoning quality, and reliability precede cost, tokens, context, and latency. Search for a semantically matching validated tool first; do trivial reliable work directly; otherwise delegate one bounded responsibility to an appropriate role.

Use premium reasoning predictively for consequential architecture, security, migrations, durable data, concurrency, destructive effects, public contracts, or contradictory requirements. Do not try a weaker model first when failure can cause subtle or difficult-to-reverse harm.

Give a subagent every critical requirement, constraint, contract/spec link, ownership boundary, authority/human-gate boundary, and relevant prior evidence. Do not fork full conversation history by default, but never omit necessary context to save tokens. Parallelize only independent read work or explicitly non-overlapping writes; avoid shared mutable validator resources. Load the global detailed routing policy when selection or escalation is non-trivial.
